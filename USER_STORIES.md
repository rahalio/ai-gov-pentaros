# Pentaros — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Economic development programme director

- As a programme director, I want each pillar to show a named owner and health status, so that “vibrant ecosystem” is an accountable list rather than a speech line.
- As a programme director, I want to refuse endorsement of a corporate AI case that has no reskilling budget, so that public support does not subsidise displacement without transition.
- As a programme director, I want growth claims itemised by automation, augmentation, and diffusion channels, so that the +1pp story stays falsifiable.

### Corporate transformation lead

- As a transformation lead, I want my firm’s AIQ position and the evidence required to move toward collaborative inventor, so that board investment targets invention and partnership rather than slideware.
- As a transformation lead, I want to register partnerships with universities and startups under instruments with review dates, so that ecosystem collaboration is operational.

### Skills and labour official

- As a skills official, I want displacement-risk groups tagged to each scaled automation initiative, so that SETA and public employment programmes can aim reintegration where risk concentrates.
- As a skills official, I want leading education indicators tracked separately from graduate supply outcomes, so that multi-year fixes are not declared failed prematurely.

### University / science-council liaison

- As a liaison, I want fellowships and joint labs counted toward the university pillar only when funded and staffed, so that MoUs theatre does not inflate readiness.

### Responsible-AI / privacy officer

- As a privacy officer, I want data-quality and privacy risks with owners on every programme, so that regulation lag is visible.
- As a responsible-AI officer, I want high-impact deployments blocked from endorsement until accountability for model error is assigned, so that partner-not-tool rhetoric has teeth.
- As an administrator, I want firm-level AIQ detail restricted while publishing aggregate pillar health, so that trust in the programme survives competitive sensitivity.
